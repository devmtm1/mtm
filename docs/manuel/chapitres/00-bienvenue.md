Ce guide apprend à **toute l’équipe de MTM Immobilier** à se servir du back-office : commerciaux, responsables, direction, comptabilité, gestion locative, vérifications, chantiers, administration.

Il se lit **dans le navigateur**, sans rien installer. Pour retrouver une explication, tapez un mot dans la barre de recherche en haut (ou appuyez sur <kbd>/</kbd>).

![Le tableau de bord du back-office](img/02-accueil.png)

## Par où commencer ?

1. Lisez les chapitres **« Pour tout le monde »** (une vingtaine de minutes) : se connecter, se repérer, le tableau de bord, les tâches et l’agenda, les notifications.
2. Lisez ensuite le chapitre de **votre métier**. Choisissez-le dans le menu **« Je suis… »** en haut de la page : le guide vous signale les chapitres qui vous concernent.
3. Gardez le guide ouvert dans un onglet : il est fait pour être consulté en travaillant.

## Ce que vous voyez dépend de votre rôle

Chaque personne a un **rôle** qui définit ce qu’elle voit et ce qu’elle peut faire. Un commercial ne voit pas les finances ; la comptabilité ne modifie pas les prospects. Si un menu décrit dans ce guide n’apparaît pas chez vous, **c’est normal** : il n’est pas prévu pour votre rôle. Le chapitre *Qui peut faire quoi* récapitule les droits de chaque rôle.

> Les captures d’écran de ce guide montrent des **données fictives** (clients, montants, références inventés). Les vôtres afficheront vos propres dossiers.

## Une règle valable pour tout le monde

Chaque action est **enregistrée au nom de la personne connectée** (journal d’audit). Ne prêtez jamais votre compte : en cas d’erreur, c’est vous qui seriez désigné.
