## Les notifications

La **cloche** (en haut à droite) vous prévient quand quelque chose vous concerne. Un point rouge signale du nouveau.

![Mes notifications](img/12-notifications.png)

Les événements qui peuvent vous alerter :

- **Commercial** : nouveau prospect, relance CRM en retard, nouveau dossier de vente, paiement reçu à valider, réservation expirée, document manquant dans un dossier réservé ;
- **Organisation** : tâche assignée, tâche en retard, tâche à rendre bientôt, rappel de rendez-vous, invitation à un événement, nouveau message sur un dossier ;
- **Immobilier** : mandat proche de l’échéance, impayés de loyer à relancer, demande de location, demande de séjour, demande de résiliation ;
- **Métiers** : nouvelle mission, nouveau chantier, chantier en retard ou hors budget, opération financière à valider ou rejetée, nouveau message du site.

Cliquer sur une notification vous amène **directement** sur la fiche concernée.

### Régler ce que vous recevez

**votre nom (en haut à droite) › Mes notifications** :

- **Tout marquer comme lu** vide la cloche ;
- vos **préférences** : recevoir ou non les alertes par **e-mail**, par **SMS**, par **WhatsApp** (avec votre numéro de téléphone) ;
- l’e-mail ne part que si **la règle de MTM le prévoit et que vous ne l’avez pas coupé**.

> Les SMS et WhatsApp partent par le **fournisseur de messagerie** que l’administrateur technique a configuré sur le serveur (il peut en changer à tout moment). Tant qu’aucun n’est configuré, ces cases n’ont pas d’effet (l’écran le précise).

**Qui est prévenu de quoi** (groupes de destinataires, canaux) se règle dans *Règles de notification* : voir le chapitre *Administration*.

## Retrouver un document

**Documents** (menu principal) réunit les documents de **tous les modules** : titres fonciers, plans, contrats, reçus, rapports, quittances, factures.

![Page Documents](img/13-documents.png)

- Vous ne voyez que les documents des modules que **votre rôle** peut consulter.
- La recherche porte sur le **titre**, le **type** et la **référence du dossier** — pas sur le contenu des fichiers.
- Filtres : **module**, **type**, **période** (du… au…), puis **Effacer**.
- Chaque ligne indique le **module**, le **dossier**, le **type**, la **date**, et si le document est **diffusé** (visible hors de MTM : site public, espace client, propriétaire, locataire).
- L’icône **fichier** ouvre le document ; l’icône **dossier** ouvre la fiche qui le porte.
- La pagination en bas : choisissez **10, 25, 50 ou 100** lignes par page et naviguez avec les numéros.

### Ajouter un document

On ajoute un document **depuis la fiche** à laquelle il appartient (mandat, bien, dossier de vente, mission, chantier, bail…), bloc **Documents** → **Ajouter**. Donnez-lui un **titre clair** (« Contrat de réservation signé — Fall ») et choisissez son **type**.

> **Attention** — Un document « diffusé » est visible par le client ou le propriétaire. Vérifiez qu’il ne contient rien d’interne avant de le diffuser.

## Les documents PDF de MTM

Les documents générés par l’application (factures, rapports, quittances, contrats, rapports de la direction) portent l’**en-tête de MTM** : logo, NINEA, RCCM, adresse, banque. Ces mentions se règlent dans **Administration › Identité de l’entreprise**.
