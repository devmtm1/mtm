titre: Petit lexique
groupe: reference
resume: Les mots utilisés dans le back-office, expliqués simplement.
roles: tous
---

| Mot | Sens |
| --- | --- |
| **Acompte** | Somme versée à la réservation, déduite du prix. |
| **Audit (journal d’)** | Historique de qui a fait quoi, quand. |
| **Bail** | Contrat de location d’un bien au mois. |
| **Bien** | Un terrain, une villa ou un appartement suivi par MTM. |
| **Bien disponible** | Bien publié sur le site et proposable à un client. |
| **Brouillon** | Fiche enregistrée mais pas encore publiée sur le site. |
| **Caution** | Somme versée en garantie par un locataire ou un voyageur, restituée à la fin (avec retenue justifiée éventuelle). |
| **Clôture (mensuelle)** | Mois figé en finances : plus aucun mouvement ne peut y être ajouté ou modifié. |
| **Commission** | Rémunération du commercial sur une vente soldée. |
| **Commission de gestion** | Part des loyers que MTM garde pour gérer un bien. |
| **Constat** | Compte rendu d’une visite de vérification sur place (avec photos). |
| **Contre-passation** | Annulation d’un paiement déjà validé (erreur, rejet, remboursement). |
| **Dossier bloqué** | Dossier ouvert qui n’a plus bougé depuis un délai. |
| **Dossier de vente** | Le suivi d’une vente : un client, un bien, réservation, paiements. |
| **Échéance** | Date à laquelle un paiement ou une action est attendu. |
| **Échéancier** | Calendrier des versements d’un client ou des loyers d’un bail. |
| **Encaissements** | Argent reçu (loyers et prix de vente compris). |
| **État des lieux** | Constat pièce par pièce de l’état d’un logement à l’entrée et à la sortie. |
| **Exclusivité** | Mandat confié à MTM seule : le bien ne peut pas être sous un autre mandat exclusif actif. |
| **GED** | Gestion électronique des documents : la page *Documents*. |
| **Jalon** | Étape marquante d’un chantier (fondations, élévation, toiture…). |
| **Lot** | Un bien confié à MTM dans le cadre d’un mandat. |
| **Mandat** | Autorisation donnée par un propriétaire de vendre, louer ou gérer ses biens. |
| **Marge** | Prix public moins prix d’acquisition d’un bien : sert au calcul du revenu de MTM. |
| **Mission** | Une vérification ou une démarche confiée par un client à MTM. |
| **NINEA / RCCM** | Identifiants légaux de l’entreprise, imprimés sur les documents. |
| **Notification** | Alerte dans la cloche (et par e-mail si prévu). |
| **Objectif** | Cible mensuelle d’un commercial (ventes, chiffre d’affaires, commissions). |
| **Pipeline** | Les prospects rangés selon leur étape, de « Nouveau » à « Vente conclue ». |
| **Préavis** | Délai entre la demande de départ d’un locataire et son départ (30 jours par défaut). |
| **Prospect** | Personne intéressée par un bien, pas encore cliente. |
| **Qualifier** | Connaître la zone, la surface, le budget et l’objectif d’un prospect. |
| **Quittance** | Document prouvant qu’un loyer a été payé. |
| **Réservation** | Bien bloqué pour un client pendant un délai, contre un acompte. |
| **Relance** | Action prévue à une date pour recontacter un prospect ou un débiteur. |
| **Résiliation** | Fin anticipée d’un bail à la demande du locataire ou de MTM. |
| **Responsable** | Personne chargée d’un dossier, d’un bien ou d’une mission. |
| **Revenu de MTM** | Ce qui reste réellement à MTM (marges, commissions de gestion, prestations). |
| **Rôle** | Ensemble de droits attribué à une personne. |
| **Saisie** | Dépense ou recette entrée à la main en finances, validée par une autre personne. |
| **Séjour** | Location à la nuit d’un bien. |
| **Soldé** | Prix intégralement payé : la vente est conclue. |
| **Statut** | État d’un dossier (en cours, réservé, soldé, annulé…). |
| **Titre foncier** | Document juridique prouvant la propriété d’un terrain. |
| **2FA** | Double authentification : un code à 6 chiffres en plus du mot de passe. |
| **Visite et retour** | Un bien proposé à un client, avec la date de visite et ce que le client en a pensé. |
